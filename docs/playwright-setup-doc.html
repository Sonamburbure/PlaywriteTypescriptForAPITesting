Packages Installed

The following packages were installed to build the framework from scratch.

  1. 1
    Project folder was created and npm was initialized
    mkdir PlaywrightProject
cd PlaywrightProject
npm init -y

    "type": "module" was added to package.json to enable ES module imports.

  2. 2
    Playwright was installed
    npm install --save-dev @playwright/test playwright
  3. 3
    TypeScript and execution tools were installed
    npm install --save-dev typescript ts-node tsx

    tsx was used to run TypeScript files directly without a separate build step.

  4. 4
    Environment and utility packages were installed
    npm install dotenv                # loads .env files into process.env
npm install --save-dev cross-env  # sets env vars cross-platform (Windows + Mac)
  5. 5
    Chromium browser was installed for UI tests
    npx playwright install chromium

    Playwright downloaded and managed the Chromium browser used to run all UI test specs.

  6. 6
    TypeScript config was created
    tsconfig.json
    {
  "compilerOptions": {
    "target": "ES2022",
    "module": "ES2022",
    "moduleResolution": "bundler",
    "strict": true,
    "esModuleInterop": true
  },
  "include": ["src", "tests"]
}
  7. 7
    Playwright config was created with two projects — api and ui
    playwright.config.ts
    import { defineConfig } from '@playwright/test';
import dotenv from 'dotenv';

const args = process.argv.join(' ');
const defaultEnv = args.includes('.api.spec') ? '.env.dev'
                  : args.includes('.ui.spec')  ? '.env.stage'
                  : '.env.stage';
const envFile = process.env.ENV_FILE || defaultEnv;
process.env.ENV_FILE = envFile; // persisted so worker processes inherit correct env
dotenv.config({ path: envFile, override: true });

export default defineConfig({
  testDir: './tests',
  timeout: 600000,
  globalSetup: './src/global-setup.ts',
  projects: [
    {
      name: 'api',
      testMatch: /.*\.api\.spec\.ts/,
      use: { ignoreHTTPSErrors: true }
    },
    {
      name: 'ui',
      testMatch: /.*\.ui\.spec\.ts/,
      use: {
        baseURL: process.env.BASE_UI_URL,
        storageState: 'storageState.json',
        headless: process.env.HEADLESS === 'true',
        viewport: null,
        trace: 'on', video: 'on', screenshot: 'on'
      }
    }
  ]
});

05

API Automation Built

Architecture

Each API module was given its own TypeScript class in src/api/. A global-setup file was written to log in once before all tests, store the auth token in memory via tokenStore, and make it available to every API class.

src/global-setup.ts — API login was implemented as follows
const loginRes = await apiContext.post('/api/login', {
  data: {
    email:       process.env.API_EMAIL,
    password:    process.env.API_PASSWORD,
    tenant_name: process.env.TENANT_NAME
  }
});
const body = await loginRes.json();
setAuthToken(body.token);
setTenantPath(body.tenant_cname);
setLogonAs(body.logon_as);
src/api/EventApi.ts — Each module was wrapped in a class like this
export class EventApi {
  constructor(private apiContext: APIRequestContext) {}

  async createEvent(payload: any) {
    const { token, tenantPath, logonAs } = getHeaders();

    const response = await this.apiContext.post(
      `${BASE_API_URL}/${tenantPath}/api/${logonAs}/event`,
      { headers: { Authorization: `Bearer ${token}`,
                   'x-automate-secret': process.env.AUTOMATE_SECRET },
        data: payload }
    );
    const body = await response.json();
    if (body?.error_msg) throw new Error(body.error_msg);
    return body;
  }
}
tests/Event.api.spec.ts — Each test spec was written like this
test('Create Event', async ({ request }) => {
  const eventApi = new EventApi(request);
  const result  = await eventApi.createEvent({ ... });
  expect(result.eventid).toBeDefined();
});

06

UI Automation Built

Architecture

UI tests were built using the Page Object Model pattern. Global-setup was configured to launch a Chromium incognito browser, log in once, handle the tenant-selection dialog if present, and save the authenticated session to storageState.json. All UI test specs reused this saved session — no repeated logins were needed.

src/global-setup.ts — UI login was implemented as follows
const browser = await chromium.launch({ headless: false, args: ['--incognito'] });
const page    = await browser.newContext({ viewport: null }).then(c => c.newPage());

await page.goto(process.env.BASE_UI_URL, { waitUntil: 'load' });
await page.getByPlaceholder('Email').fill(process.env.EMAIL);
await page.locator('input[name="password"]').fill(process.env.PASSWORD);
await page.locator("//button[normalize-space()='Login']").click();

// Some environments show a tenant-selection dialog after login
try {
  await page.waitForSelector('input[type="radio"]', { timeout: 5000 });
  await page.locator('input[type="radio"]').first().click(); // selects DREAM EVENTS
} catch { /* no dialog on this environment — skip */ }

await page.waitForURL(url => url.toString().includes('#/home'));
await context.storageState({ path: 'storageState.json' });
src/pages/CreateEventPage.ts — Page Object Models were written like this
export class CreateEventPage {
  readonly menuBtn        = this.page.locator("i[role='button']");
  readonly eventListBtn   = this.page.locator("a[href='#/home/events']");
  readonly createEventBtn = this.page.getByRole('button', { name: 'Create Event' });

  constructor(private page: Page) {}

  async createEvent() {
    await this.menuBtn.click();
    await this.eventListBtn.click();
    await this.createEventBtn.click();
  }
}
💡
storageState.json was auto-regenerated each time global-setup ran. UI tests loaded this file to skip the login step entirely, which made each test faster and independent.

NPM Run Scripts Configured

The following run scripts were configured in package.json to make it easy to run tests against any environment with a single command.

ScriptEnvWhat It Runs
npm run api:dev dev All API tests against dev environment
npm run api:stage stage All API tests against stage environment
npm run api:prod prod All API tests against production
npm run smoke:dev dev Full smoke test (end-to-end flow) on dev
npm run smoke:stage stage Full smoke test on stage
npm run ui:stage stage All UI tests against stage (headless)
npm run ui:prod prod All UI tests against production (headless)
npm run report — Open the last Playwright HTML report in browser

Individual test files were also run directly

# Run one API spec
npx playwright test tests/Event.api.spec.ts

# Run one UI spec with visible browser
npx playwright test tests/ui/CreateEventPage.ui.spec.ts --headed

# Run the smoke test on dev
npx playwright test tests/smoke.api.spec.ts
